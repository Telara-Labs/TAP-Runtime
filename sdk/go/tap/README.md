# TAP Go SDK

This small standard-library-only client implements the JSON-line broker used by compiled WASI primitives. `Client.Request(method, fields)` supports `tools`, `call`, `exec`, `read`, `write`, and `fetch`; it creates a unique request ID, matches the reply, and returns the runner fields including result, stdout/stderr, command exit, HTTP status, refusal, violation/landed, unknown, and gated state. `Client.Call(alias, arguments)` is a typed convenience for connector calls and converts a nonzero call exit to a failed error. `Client.Read(path)` preserves empty-file success and converts a nonzero read exit into an error. `Client.Return(stdout, stderr, exit)` sends the final result frame.

Refusal, violation, unknown, malformed, and mismatched responses become typed `*tap.Error` values; unknown takes precedence over the refused message that accompanies an unknown outcome. Generic `Request` preserves command exit and HTTP status for the caller to interpret, including a nonzero `write` exit, so callers must check `Reply.Exit` before treating a write as successful. The SDK performs no filesystem, network, subprocess, or environment access itself. The Go language example includes a local copy of this source so it builds in isolation.
